INTRODUCTION                                                  *blink-cmp-tmux*

blink-cmp-tmux provides tmux command completions for blink.cmp. It completes
tmux commands with usage signatures, alias information, and man page
descriptions.

==============================================================================
INSTALLATION                                     *blink-cmp-tmux-installation*

With vim.pack (Neovim 0.12+): >lua
    vim.pack.add({
      'https://git.barrettruth.com/barrettruth/blink-cmp-tmux',
    })
< With luarocks: >sh
    luarocks install blink-cmp-tmux
<

==============================================================================
CONFIGURATION                                   *blink-cmp-tmux-configuration*

Register the source with blink.cmp: >lua
    require('blink.cmp').setup({
      sources = {
        default = { 'tmux' },
        providers = {
          tmux = {
            name = 'Tmux',
            module = 'blink-cmp-tmux',
          },
        },
      },
    })
<
